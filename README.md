# 同城小程序二手交易同城生活求职招聘相亲交友同城小程序校园同城生活小程序

源码地址：ym7k.com/19326/

一套功能齐全的同城便民信息发布小程序，适合搭建本地同城、县域商圈、校园同城平台，用户自主发布信息，覆盖本地生活全品类，后台完整管理，私有化部署，轻松做本地流量平台。

### ✅ 前端核心板块

- **首页**：顶部搜索、轮播广告、快捷入口导航，热门推荐、最新发布信息流
- **五大核心分类**
  - ✔ 求职招聘：企业招工、个人找工作
  - ✔ 房屋租赁：租房、房源出租、合租、商铺转让
  - ✔ 二手交易：闲置物品买卖、数码、家电、物品转让
  - ✔ 相亲交友：本地征婚、交友信息发布
  - ✔ 生活服务：家电维修、上门服务、各类便民接单
- **新闻资讯页**：平台公告、本地资讯、精选内容展示
- **发布页**：用户一键发布信息，选择对应分类上传图文
- **电话板块**：本地便民黄页，维修、商家联系电话汇总
- **个人中心**：我的发布、收藏、消息、资料管理

### ✅ 后台管理功能

- **分类管理**：自由新增、编辑、删除分类，自定义分类图标与排序权重，可单独配置电话黄页分类
- **会员管理**：平台用户账号查看、管控
- **轮播图管理**：首页 banner 广告上传、切换
- **文章 / 资讯管理**：新闻、公告编辑上架
- **评论管理**：审核、管理用户留言评论
- **广告图管理**：平台广告位配置
- **订单管理**：信息置顶、付费推广订单查看
- **权限、系统配置**：基础参数、字典配置，灵活调整平台规则

### ✅ 核心亮点

✅ 一站式同城信息平台，五大业务模块集成，不用分开搭建多个系统
✅ 分类高度自定义，既能做县域同城，也可以改成校园同城
✅ 自带便民黄页，汇聚本地商家、维修师傅联系电话
✅ 信息流展示，支持置顶付费推广，平台变现方式成熟
✅ 后台操作简单，可视化管理全部用户发布内容，方便审核防违规
✅ 适合本地站长、校园创业者、社群运营搭建同城流量平台

### ✅ 适用场景

县城同城便民平台、乡镇本地信息号、校园同城圈、社区生活圈、本地二手 + 招工 + 租房综合信息平台
